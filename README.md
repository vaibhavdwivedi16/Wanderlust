Wanderlust ✈️
A clean, minimalist, and aesthetic Travel & Tourism Website built entirely with pure HTML5 and CSS3. Featuring a sleek dark theme layout, smooth hover transitions, high-quality curated destination imagery, travel packages, must-see attractions, and practical travel info.
Proudly created by a developer from a growing community channel with 69k subscribers!
✨ Features
Pure HTML5 & CSS3: Lightweight, fast, and built without any JavaScript frameworks or libraries.
Minimalist Dark Theme: Designed with a modern, eye-friendly dark color scheme inspired by clean design systems.
Curated Sections:
Hero Section: Engaging introductory banner with quick action links.
Popular Destinations: High-res image cards showcasing iconic spots like Kyoto, Amalfi Coast, and Reykjavik.
Travel Packages: Clean itinerary breakdowns complete with pricing and feature lists.
Must-See Attractions: Highlight cards featuring stunning landmarks and brief descriptions.
Travel Essentials: Practical guidelines covering visas, currency, and local etiquette.
Fully Responsive Layout: Built using modern CSS Grid and Flexbox for seamless adaptation across mobile, tablet, and desktop viewports.
🚀 Tech Stack
HTML5 (Semantic markup)
CSS3 (Custom styling, Grid, Flexbox, transitions)
Unsplash (Curated high-resolution photography)
🛠️ Getting Started
Clone or download this repository to your local machine.
Ensure both index.html and style.css are saved in the same directory.
Open index.html in any web browser or use a live server extension (like VS Code Live Server) to view the site.
